# Fonts

Place **JetBrains Mono Nerd Font Mono** Regular here so the site uses it.

1. Download from [Nerd Fonts](https://www.nerdfonts.com/font-downloads) → **JetBrains Mono** (patched).
2. From the zip, copy the **Regular** weight file into this folder and rename it to match:
   - `JetBrainsMonoNerdFont-Regular.ttf`  
   or  
   - `JetBrainsMonoNerdFont-Regular.woff2` (if you have a woff2 build)

The CSS expects either:
- `JetBrainsMonoNerdFont-Regular.woff2`, or
- `JetBrainsMonoNerdFont-Regular.ttf`

If your zip has different names (e.g. `JetBrains Mono Nerd Font Mono Regular.ttf`), rename the file to `JetBrainsMonoNerdFont-Regular.ttf`.

Until the file is present, the site will fall back to system monospace (Courier).
